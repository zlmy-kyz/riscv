## 1. 设计与保存范围

修改前39项myriscv/*.v、RISCV.pds、有效FDC已复制到`sim/cnn/integrated_20261016_a/baseline/`并记录manifest。新增`myriscv/cnn_digits_engine.v`、`cnn_mmio.v`；基础4模块源码不变。修改data_bus_interconnect/soc_top/soc_ddr3_top/board_top、PP输出锁与读仲裁参数；主PDS加入全部6个CNN文件，board_top启用ENABLE_CNN。未改CPU核、DDR桥/缓存、DDR/FIFO IP、有效FDC和成功固件。

`cnn_digits_engine`按digits10_int8_v1执行三层卷积8/16/32→GAP16→FC10。bank0/bank1各2048×8同步读写，权重6152×8，bias66×32，shift4×5；分数10×32寄存器。存储器数组不复位、不初始化假权重，控制器以完整模型装载与完整输入计数保护所有使用路径。权重/bias/激活均顺序地址同步读，READ/WAIT/SEND分离，MAC乘与加分拍。逻辑容量不等于PDS实际RAM/DSP数量，资源映射等待本版PDS。

输入1024灰度字节写bank0；conv1输出bank1共2048，conv2输出bank0共1024，conv3输出bank1共512，GAP按每通道HWC步长32读16点写bank0的32字节，FC读该向量。每层输出按y/x/oc递增，卷积内循环ky/kx/ic；padding量化0。全网输出166208次乘加（含padding），复用基础MAC/重定标/GAP模块。FC10比较signed分数，平分保留较小类别号，分数不解释成概率。

## 2. DDR、输入锁与异常

CNN只读PP输出0x42000000–0x42006bff；原生地址从0x00800000起，每256bit拍加8，ARLEN0、ID4，共864拍。每次发AR前都留有一个完整256bit缓存，收完一拍后按低字节先行串行送适配，直到32字节均被接受才发下一AR；支持AR/R同边沿。RGB跨拍保留适配内部通道状态，最后一拍最后一字节产生LAST。收到全部27648字节、适配完成并输出1024字节后才启动计算。

内层保持CPU/PP整笔轮转，外层以CPU+PP组与CNN整笔轮转。既有read_arbiter增加PP_ID参数，默认3，外层4；CPU的len/id/ap完整透传。读返回ID/RLAST/数量错或无owner时隔离至复位，错误拍不再路由给任何消费者。外/内错误OR给PP和CNN。嵌套仲裁不等于三方等带宽，优先保证有限事务进展。写口完全保持原CPU/相机/PP结构，CNN没有DDR写通路。

START接受时要求MODEL_VALID、PP DONE且不busy、软件EXPECTED_BUF/SEQ与PP真实元数据一致，无读协议错误。随后CNN busy即PP output_hold；PP START和CLEAR在该锁期间返回访问错误，不能覆盖或失效输入。锁一直保持到整网完成/安全取消，虽然后半段计算不再读DDR，首版仍保守锁住。CPU总线单请求保证CNN START与PP START/CLEAR不同时被接受。PP SELECT/EXPECTED_SEQ配置不改变已发布结果元数据。CNN可以重复处理同一PP输出，但训练/验收必须记录SEQ而不能当成新采图。

ABORT或3秒超时：计算/串行/等待适配阶段直接作废；已经公开AR的ADDR或等待R的RESPONSE状态必须保持请求并收完返回才撤busy/锁。取消不生成DONE，部分激活无效；权重模型保持，可再次处理完整输入。DDR永久不响应时保持busy/锁等待全局复位。读协议错误进入HANG保持锁至全局复位；CPU若因DDR取指受阻不保证仍可串口诊断。复位清控制和模型有效位，须重新完整装载模型。计时器在3秒处饱和，不表示致命错误后的实际等待时长。

## 3. MMIO：0x10004000–0x100040ff

ABI ID `0x434e4e01`。只接受32bit对齐访问；写须全4lane strobe，未列偏移/非法写返回既有access fault，副作用仅发生在请求握手时。此窗口位于MMIO，指令总线不映射；没有新增DDR张量地址或缓存维护操作。

| 偏移 | 名称 | 语义 |
|---|---|---|
| 00 | ID | RO 434e4e01 |
| 04 | CTRL | W单命令：1 START，2 ABORT，4 CLEAR，8 MODEL_BEGIN；读0 |
| 08 | STATUS | bit0 BUSY、1 DONE、2 ERROR(含读协议)、3 MODEL_VALID、4 LOADING、5 LOAD_ERROR |
| 0c | MODEL_ID | RW非零32bit软件包标识；只在LOADING且COUNT=0时可写 |
| 10 | MODEL_DATA | W下一参数word，读0 |
| 14 | MODEL_CRC | R当前CRC；W期望CRC以COMMIT模型 |
| 18 | LOAD_COUNT | RO已接受参数word数量，最终6222 |
| 1c | EXPECTED_SEQ | RW仅空闲可写 |
| 20 | EXPECTED_BUF | RW0=A/1=B，仅空闲可写 |
| 24 | RESULT_SEQ | RO，DONE才有效否则0 |
| 28 | RESULT_BUF | RO，DONE才有效否则0 |
| 2c | CYCLES | RO本作业busy周期，结束冻结，超时饱和 |
| 30 | READ_BEATS | RO本作业正确接收拍数，正常864 |
| 34 | GRAY_BYTES | RO当前适配输出数，正常DONE时1024 |
| 38 | CLASS | RO，DONE时数字0–9，否则0 |
| 3c | ERROR_CODE | RO：1取消、2超时、3读协议、4输入/计数、5计算错误 |
| 40..64 | SCORE0..9 | RO，共10个signed32，DONE才有效否则0 |

0x68..0xff非法；不存在读回权重或任意写激活RAM的生产接口。STATUS的DONE是结果有效依据，CLASS=0不代表结果有效。START和MODEL_BEGIN清DONE；CLEAR仅空闲且无致命读错时清结果/作业错误，不清模型有效。ABORT空闲时为无副作用命令；busy时作业取消。LOAD_ERROR通过新的MODEL_BEGIN清除，不能靠CLEAR绕过。

## 4. 模型装载编码

空闲时CTRL=8：清MODEL_VALID、DONE、LOAD_COUNT/LOAD_ERROR，CRC初值ffffffff，MODEL_ID清0，进入LOADING。先写非零MODEL_ID，再依次向DATA写6222个word：

1. index0..6151：weights.bin的6152个字节，各用**零扩展32bit word**写入；0x80(-128)拒绝，其他0..255合法。负权重以低字节补码表示，不写0xffffffff来表示-1。
2. index6152..6217：bias.bin中的66个小端signed32值，以word写入。硬件采用保守界 `-2145142783 <= bias <= 2145142783`，保证在最多144项、输入绝对值128、权重绝对值127下累加不溢出。导出器必须同时满足合同通道精确界和这个保守界。
3. index6218..6221：conv1/2/3/FC四个shift，32bit值0..31。

各层权重顺序/偏移、bias顺序沿digits10合同。FPGA只消费导出的shift，不存浮点scale/F；软件须验证Fin/Fw/Fout关系、合同ID和模型类别。MODEL_ID用于包匹配，不是硬件验证过的SHA或训练质量证明。

CRC为反射IEEE CRC32，多项式edb88320、初值ffffffff、最终取反，覆盖以上**6222个word的小端4字节，共24888字节**，不包括MODEL_ID。不是紧凑weights.bin+bias.bin的CRC。COMMIT：向0x14写期望CRC；仅LOADING、COUNT=6222、LOAD_ERROR=0、ID非零、CRC匹配才置MODEL_VALID并退出LOADING。任何参数格式错误/超量写使LOAD_ERROR置位，需从BEGIN重新装载。CRC不匹配不提交，可核查后重试提交或重新BEGIN；不自动接受未完整模型。

busy期间模型装载、BEGIN、改EXPECTED等均拒绝；只有ABORT可改变正在执行的作业。新模型装载失败不会回退到旧有效模型。CPU只负责装载/控制，卷积不由CPU执行。

## 5. 软件顺序与Sol任务边界

先装载一个满足合同的固定参数包并核MODEL_VALID/COUNT/CRC/ID；Camera领取帧→PP正常完成→保存PP RESULT_BUF/SEQ→CNN设置EXPECTED→START→轮询DONE/ERROR（有软件超时）→核RESULT_BUF/SEQ、864拍、1024字节→读10分数/CLASS/周期。PP完成后源Camera缓冲可按原所有权合同释放；CNN锁的是独立PP输出，不是Camera帧。正常第一版串行执行，不在CNN busy期间启动下一次PP。

当前没有新训练包或CNN测试BIN，不提供上板运行命令。用户先用主RISCV.pds重新综合/映射/布局布线，检查本版真实CNN路径时序与RAM/DSP映射；本对话不启动PDS。时序通过后Sol准备本版关键组与固定测试包，DeepSeek依封存代码执行，原证据复核后才给上板软件。模型可用确定性合成权重验证逐元素算术，但不能据此宣称数字识别准确率。

关键组要求：

- 复用基础模块要求；整网独立宽整数参考逐层检查1024/2048/1024/512/32及10分数；至少非对称输入/正负权重/非零bias、padding、负半值/饱和、FC平分。记录166208次项接受、HWC地址和层边界，不能只比较argmax。
- 同步RAM首/尾地址、读等待、bank交换、同一输出地址连续两作业、全局复位后未装模型拒绝；错误权重/bias/shift、缺项/超量/坏CRC、busy改模型及MMIO尺寸/strobe/非法偏移。
- DDR首末地址/864拍/27648串行字节、AR/R同拍和延迟、RGB跨32byte边界、CPU/PP/CNN轮转、无RREADY的整拍接收；在实际生产连接下检查PP START/CLEAR锁定和成功/取消后解锁。
- ABORT在AR背压、等R、SERIAL、计算最后结果边沿；超时等待与永久无R不提前解锁；坏RID/RLAST/孤立R不交付错误数据，HANG至复位。最后计算结果与ABORT同拍时不能发布DONE。
- 真实CPU最小程序完成参数装载、一次固定输入CNN、完整10分数对照及错误访问；不重复历史720p长仿真/CoreMark/ISA/PHY全套。新共享读仲裁行为必须有本版原始证据，不能继承旧PP PASS。
