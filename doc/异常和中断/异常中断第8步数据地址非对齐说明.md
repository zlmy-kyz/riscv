# 异常与中断：第 8 步数据地址非对齐

本步在 [`mycpu_sync.v`](/D:/riscv/RISCV/myriscv/mycpu_sync.v) 的 EX 级检查 load/store 的**完整 ALU 有效地址**。半字访问 LH/LHU/SH 要求 `addr[0]=0`；字访问 LW/SW 要求 `addr[1:0]=0`；LB/LBU/SB 允许任意字节地址。故障 load 产生 cause 4，故障 store 产生 cause 6；`mtval` 保存完整有效地址，`mepc` 保存访存指令自身 PC。

## EX 检测和副作用

| 信号 | 作用 |
|---|---|
| `ex_access_half` | 由 ID/EX 中的 LH、LHU、SH 类型位组合得到。 |
| `ex_access_word` | 由 ID/EX 中的 LW、SW 类型位组合得到。 |
| `ex_data_misaligned` | 有效流水项且无已有 ID 异常时，检查半字 bit0 或字 bit[1:0]。字节指令不进入该条件。 |
| `ex_exc_valid/cause/tval` | 先保留已有 ID 异常；否则采纳 EX 非对齐结果，并以 `alu_result` 全 32 位作为 `tval`。记录与 PC、指令字一起送往 EX/MEM、MEM/WB。 |
| `ex_store_commit` | 在 EX 同一周期要求 `!ex_exc_valid`，同时要求无老故障、未取消、非复位；驱动 RAM `wr_en` 和全部字节写使能。 |
| `mem_fwd_data` | 故障项置零；`fwd_mem_en`、`fwd_wb_en` 与 GPR 写口也由异常标志关断，故障 load 不会把读出数据当成正常结果。 |

EX 存数端口原本就在本级的上升沿写 RAM，所以必须在这一拍的组合逻辑中关断 `wr_en` 和 `wr_byte_en`。若等异常进入 EX/MEM 或 WB 才关断，目标字可能已发生不可撤销的部分写入。若 EX/MEM、MEM/WB 有老故障，当前年轻 store 也不能写入；已有非法 CSR 的 WB 检查结果同样进入这一保护条件。

当前普通 BRAM 没有独立读请求使能，地址口和读时序保持原样。故障 load 可能使 BRAM 内部锁存读地址，但不会前递、写 GPR 或正常退休。将来接入总线或有读副作用的 MMIO 时，必须在请求端增加有效/许可门控，不能沿用“读出后丢弃”做法。

## 验证

[misaligned_data_step8.S](/D:/riscv/RISCV/difftest/prog/misaligned_data_step8.S) 依次制造十一次非对齐访问：LH/LHU 各一次、LW 的偏移 1/2/3、SH 的偏移 1/3、SW 的偏移 1/2/3，以及有效地址 `0x1301` 的 LH。最后一例核对 `mtval` 保留高位，而不是保存被当前 BRAM 地址口截断后的地址。handler 位于软件设置的 `mtvec=0x180`，每次将 `mcause/mepc/mtval` 记录到 RAM，再把 `mepc` 加 4 并 MRET。专项测试台 [`tb_misaligned_data_step8.v`](/D:/riscv/RISCV/difftest/tb/tb_misaligned_data_step8.v) 逐次核对 cause 4/6、故障 PC 和原始地址。

测试在每次 trap 时检查目标字和相邻字仍为哨兵 `0x0000007b`，并在故障 store 的 EX 周期检查 `wr_en=0`、字节写使能全零。故障 load 的目的寄存器保持预置值，MEM 前递源为零。随后程序执行对齐的 LH/LHU/LW/SH/SW 和偏移 7 的 SB/LB/LBU；最终 RAM 字与 GPR 均单独比对。结果：`RESULT: PASS misaligned LH/LHU/LW/SH/SW, precise RAM/GPR suppression, aligned and byte access`。
