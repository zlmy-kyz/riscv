# PDS 真实片内 IP＋DDR3：`lb` 测试准备

日期：2026-09-29。承接 `doc/board/PDS真实片内ROM_RAM与DDR3一键仿真.md` 中的 `add` 按钮 PASS。本步骤把下一项测试切换为含 `.data` 的 `lb`，检验启动程序从真实片内 RAM 同时搬运代码和数据到 DDR。PDS 按钮完整仿真已 PASS。

## 改动与配置

- 用户在 PDS 中将 `data_ram` 初始化文件改为 `D:/riscv/RISCV/MyCpu_test/ddr_stage/lb.dat` 并重新生成 IP。核对 `ipcore/data_ram/data_ram.v` 的 `INIT_FILE` 和 `ipcore/data_ram/rtl/data_ram_init_param.v` 文件时间均为 2026-09-29 00:46:23。
- `inst_rom` 继续使用 `MyCpu_test/ddr_stage/boot_rom.dat`；启动程序未变。
- 将 `sim/pds_ddr_ip_run.tcl` 改为 `+TEST=lb +TOHOST=80001000 +EXPECTED_WRITES=273`，独立日志为 `sim/pds_ddr_ip_lb.log`。`lb.dat` 尾部清单为 `0x10d` 个代码字（269）、数据偏移 `0x2000`、4 个数据字，总复制数 273。
- `sim/pds_ddr_ip_compile.tcl`、`source/tb_soc_ddr3_pds_ip.v`、DDR3 IP、PDS 自定义 Tcl 路径和仿真顶层都不需修改。
