# DDR IP 板卡引脚分组修复（2026-10-03）

## 问题与依据

Place-0054 指向 `u_soc/u_ddr3/u_ddrphy_top/ddrphy_slice_top/i_ca_group[0].u_ddc_ca/ddc_inst`。本次检查了 Git 状态/差异，保留已有未提交改动。实际生效的源约束仍为 `constraint_check/temp_constraint_file.fdc`。

源 FDC 已按板卡绑定球位，但 DDR IP 的 IDF PAD 和生成的 PHY 内部 CA 分组仍对应旧示例。旧 A0=AA4/G1、A5=U3/G0，板卡实际 A0=T1/G0、A5=R2/G0；旧 group 0 还驱动板卡 AA1/AB1/AB3/AB2 等 G1 球位，使同一 DDC 时钟驱动的 IO 分散在不同物理 DQS 组。外部 Location 约束不能自动重新生成这些内部连接。

物理组依据厂家 [PG2L100H FBG484 引脚表 PK04003 V1.2](https://www.pangomicro.com/en/uploads/53289407_1729131942.pdf)，PDF 第 22–23 页；板卡球位依据 [板商硬件手册 v1.1](https://szlogicmatrix.com/wp-content/uploads/2025/12/RK3568_MES2L50H_100H_%E7%A1%AC%E4%BB%B6%E4%BD%BF%E7%94%A8%E6%89%8B%E5%86%8C_v1.1.pdf)及用户已确认映射。生成逻辑核对了本机 IP 1.10 的 `ui.tcl` 中 `check_ca_group_used`、`check_ca_sig_group_num`、`check_ca_dqs_en` 和生成模板。

| IP 逻辑组 | 板卡物理组/信号 |
| --- | --- |
| CA group 0 | R5/G0：A[10:0] |
| CA group 1 | R5/G1：A[14:11]、BA[2:0]、CK/CK_N、CKE |
| CA group 2 | R5/G2：CS/RAS/CAS/WE/ODT |
| 数据字节 0 | R4/G3：DQ[7:0]、DM0=N5、DQS0=P5/P4 |
| 数据字节 1 | R4/G2：DQ[15:8]、DM1=L5、DQS1=M1/L1 |

IDF 中预留 A15=Y3/G1，只用于保持厂家配置一致；当前地址宽度仍为 15，顶层没有新增 A15 管脚。A4/R3、A5/R2、BA0/AA3、RAS/W5、WE/W6 是 DQS 特殊球位，生成器同步调整了其 `*_DQS_EN` 和延迟 WCLK 路由。mem_rst_n/T3 是单端 IO，不属于 CA DDC 分组。

## 未覆盖边界

PNR 成功和当前已导入约束的时序通过不等于实板验证。DDR/参考时钟的实际 Bank 电压及参考时钟接收电气属性仍须按实物修订原理图/板厂约束确认；bitstream 的 SCBV 选项须按 PCB 接线确认并设置。主 RAM 仍为 ld_st，板级默认 DDR 地址 0x40000000，与自检 TB/镜像 0x80000000 的布局不同；上板镜像和装载/启动顺序尚须统一。当前修复不增加端口、不移动板卡球位、不改变电压，也未用额外时序例外掩盖物理分组错误。
