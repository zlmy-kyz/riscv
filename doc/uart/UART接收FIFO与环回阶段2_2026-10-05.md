## 2. uart_rx 接口、CDC 与采样

新增 `myriscv/uart_rx.v`，默认 CLK_HZ=93_750_000、BAUD=115_200、8N1、LSB first。整数分频 814 clk/bit（115171.990 baud，−0.024314%），半位 407 clk。

| 端口 | 方向 | 定义 |
| --- | --- | --- |
| clk | input | 接收工作时钟 |
| resetn | input | 低有效异步断言；调用方同步释放 |
| rx | input | 异步 RX 线，idle high |
| rx_data[7:0] | output reg | 最后一个正确接收的字节，其他周期保持，复位置零 |
| rx_valid | output reg | STOP 中心采到 1 时置 1，持续一个 clk；此时 rx_data 更新 |
| frame_error | output reg | STOP 中心采到 0 时置 1，持续一个 clk；rx_valid=0，rx_data 不更新 |
| rx_busy | output wire | START/DATA/STOP/WAIT_HIGH 期间为 1，便于观测接收与错误恢复状态 |

两级同步器 `rx → rx_meta → rx_sync` 隔离异步输入；FSM 只使用 rx_sync。rx_previous 是 rx_sync 的边沿历史寄存器，不是额外的输入 CDC 级。同步器降低亚稳态传播概率，不保证物理亚稳态绝不存在。数字仿真不模拟亚稳态概率。

相对 RX pin 下降沿，FSM 在约 2～3 个 clk 后观察到下降沿（约 21.3～32 ns）；为一个 8.68 μs bit 的约 0.25～0.37%。后续输入数据经过同样同步路径，因此固定同步延迟大部分抵消，采样相位主要剩余不到一个 clk 的边沿量化误差。该量级远小于半位裕量。物理布局/同步器实现须在后续综合与集成阶段核对。

IDLE 检测 `rx_previous && !rx_sync`，随后等待 407 clk，在 START 中心确认低；若已高，作为假起始位回到 IDLE，无 valid/error。确认 START 后每隔 814 clk 采一位，写 data_shift[0]…[7]，最后检查 STOP 中心。

以 FSM 观察下降沿的上升沿为 t_detect，采样时刻如下；所有采样使用 rx_sync，不直接读取 RX pin：

| 采样对象 | 相对 t_detect 的 clk 数 | 相对时间 ns |
| --- | ---: | ---: |
| START | 407 | 4341.333 |
| DATA0 | 1221 | 13024.000 |
| DATA1 | 2035 | 21706.667 |
| DATA2 | 2849 | 30389.333 |
| DATA3 | 3663 | 39072.000 |
| DATA4 | 4477 | 47754.667 |
| DATA5 | 5291 | 56437.333 |
| DATA6 | 6105 | 65120.000 |
| DATA7 | 6919 | 73802.667 |
| STOP | 7733 | 82485.333 |

正常帧 STOP 中心检查后回 IDLE，可以接收只有一个停止位的连续字符。错误帧进入 WAIT_HIGH，等同步输入回高后再回 IDLE，防止持续低电平反复制造 frame_error。rx_valid 与 frame_error 互斥。错误帧没有 rx_valid，不能写入 RX FIFO。

本接收器没有多数表决或复杂过采样。理想 8N1 中心采样的累计偏差受约半位窗口限制，停止位条件近似为 `9*T_external < 9.5*T_local < 10*T_external`；理想波特率相对本地约 ±5.26% 是无抖动极限估计，不是保证值。时钟量化、噪声、边沿畸变和亚稳态会缩小裕量。本轮只实测 nominal 及标称 115200 的 ±2% 波特率（117504、112896），不能将 PASS 推广到理论极限。

## 3. RX FIFO 定义

新增 `myriscv/uart_rx_fifo.v`，默认 DEPTH=16、宽度 8 bit，count 为 5 bit；同步读写、异步断言复位。连接方式在独立 TB 中为 `.wr_en(rx_valid), .write_data(rx_data)`，FIFO 在 rx_valid 置位后的下一个 clk 沿写入；本轮未新增 SoC wrapper 或永久接线。

接口：clk、resetn、wr_en、write_data[7:0]、rd_en、read_data[7:0]、empty、full、count、overflow。read_data 是当前队首（FWFT），!empty 时有效；消费者在 rd_en 的上升沿前取数据，该沿消费队首。empty 时 read_data=0，空读忽略。没有 read_valid 脉冲接口。

| 沿前状态与操作 | 行为 |
| --- | --- |
| 普通写 | 写入队尾，count+1 |
| 普通有效读 | 消费队首，count−1 |
| 非空非满同时读写 | 读旧队首、写新队尾，count 不变 |
| empty 同时读写 | 不做空读、不旁路；新字节入队，count=1 |
| full 写且无有效读 | 丢弃新字节，旧数据保留，count=16，overflow=1 |
| full 同时读写 | 消费旧队首并接收新字节，count=16，无 overflow |
| reset | 指针/count/overflow 清零，empty=1、full=0、read_data=0 |

overflow 是拒绝写入的单周期事件指示，下一拍没有拒绝写入则清零；若每拍连续拒绝写入，可连续为高，代表每拍各一次拒绝。它不是锁存状态。UART 字节间隔很长，串行满队列场景中的 overflow 为互相分离的一周期脉冲。

不复位存储数组，以 count/empty 屏蔽旧内容，复位后绝不会读出上一轮未消费数据。指针显式回绕，RTL 可参数化正深度；本轮仅验证深度 16。小数组及组合队首读适合寄存器/分布式存储实现，未实际执行 PDS 综合。

## 4. 验证方法与实测结果

新增 `source/tb_uart_rx.v`，只包含 TX、RX、FIFO 和独立检查器。使用 1 fs 时间精度的 93.75 MHz 时钟。

UART 独立驱动器采用实数 `1e9/115200 ns` 位周期，与 TX RTL 无依赖，输入从非时钟对齐的时刻开始；连续发送 Hello、00/FF/55/AA/01/80，每帧仅一个停止位。事件期望表独立检查字节顺序、LSB first、valid/error 互斥及单周期语义，且将完成事件限制在输入下降沿之后 `7733 clk + 2～3 clk` 的窄时间窗口（另允许 0.1 ns 仿真舍入）。FIFO 模型使用移动字节队列，每拍比较队首、count、empty/full、overflow，不读取 DUT 内部状态/计数器/指针。

同文件中的独立 FIFO 定向测试补足串行输入不能产生的连续工作时钟读写边界，共 209 次操作检查：连续填满/排空、空读、空同时读写、满同时读写、满连续拒绝、普通同时读写、反复回绕、满且 overflow 有效时复位及恢复。

| 验证项 | 实测结果 |
| --- | --- |
| 独立 nominal Hello + 6 个数据模式、FIFO 顺序/count | PASS |
| 假起始低脉冲 BIT/8，无 valid/error，随后正确接收 | PASS |
| STOP=0，frame_error 一周期，错误帧不入 FIFO | PASS |
| 错误后持续低 12 位，无重复错误，回高后恢复 | PASS |
| 20 个串行字节不读，保留前16字节、后4字节丢弃 | PASS，4 次 overflow |
| 满 FIFO 同拍读旧队首/写新字节，保留顺序 | PASS，无额外 overflow |
| 外部波特率 +2%、−2%，各11个模式连续发送 | PASS |
| 8 个异步起始相位 | PASS |
| 数据仅在中央40%窗口正确、两端取反的采样压力帧 | PASS，确认中心采样 |
| idle/START/DATA/FIFO 非空复位，即时清除、后续恢复 | PASS |
| 未修改 TX 连续 Hello → RX → FIFO，按序读出 | PASS |
| 阶段1 TX 原始回归 | PASS |

复位测试主动终止旧帧并将 RX 线恢复高，等待至少 11 个 bit 检查无残留事件，再发送正常字节；不保证复位释放在远端半帧中间时能恢复该已损坏帧。理应由上层允许重新同步到后续完整起始位。

最终阶段2结果：75 个正确 UART 字节、1 个错误帧、4 个满队列丢弃；FIFO 接受写入 71 次、读取 70 次，另一个已入队字节被显式非空复位清除。期望事件数与观测一致，无重复或遗漏。仿真约 7.327296 ms，退出码 0，编译/运行 Errors: 0、Warnings: 0。
