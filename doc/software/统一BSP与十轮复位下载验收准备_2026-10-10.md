## 统一流程和目录

`C源码 + BSP → 同一GCC构建 → ELF/BIN/manifest审查 → 同一PC Loader → UART LOAD → DDR CRC32 VERIFY → 唯一RUN → 严格应用输出核验 → 逐轮日志/独立总验收`。

软件根目录 `D:/riscv/RISCV/tests/bsp_workflow/`，没有新增tests/common或src层级：

| 文件 | 职责 |
| --- | --- |
| startup.S | 禁用中断，初始化gp/sp，按LMA/VMA关系处理data，清零BSS，设置DDR中的mtvec，进入main，返回后驻留循环 |
| linker.ld | 应用0x40000000低60KiB，顶部0x4000F000–0x4000FFFF为4KiB栈；旧Harvard ROM/RAM由原Loader独立维护，不合并进应用BIN |
| bsp.h、uart.c | putchar/puts/轻量printf、非阻塞接收、UART RX IRQ使能/禁用与软件队列 |
| timer.c | 93.75MHz MMIO cycle读取、用无符号差值处理单周期回绕的微秒延时 |
| trap.S、trap.c | 保存/恢复全部通用寄存器、128-byte对齐栈帧、mcause/mepc/mtval分发、mret；ECALL计数后返回下一条指令，UART外部中断读空FIFO，其他异常打印后停住 |
| crc32.c | IEEE反射CRC32、整段与分段更新接口 |
| main_hello.c、main_crc32.c、main_irq.c | Hello、独立CRC32算法验收、仅用于定向验证的UART IRQ应用 |
| core_portme.c/.h、ee_printf.c | 既有裸机端口副本，计时转到timer.c、输出转到同一putchar，算法源包原样保留在D:/riscv/RISCV/coremark-main/ |
| build.py、run.py | 统一构建/审查，以及下载和完整十轮验收入口 |

data的当前LMA=VMA，BIN含data初值，由真实UART Loader写入DDR完成初始化；startup不会从同地址片内数据RAM执行，也不会把应用代码塞入片内ROM。BSS为NOLOAD，启动逐字清零。默认中断关闭，mtvec在启用中断前就已设置。

轻量printf支持%s/%c/%d/%i/%u/%x/%X/%%及最多32列的宽度/零填充；十六进制以大写输出，不支持浮点、精度、long限定符等完整libc功能。不支持格式返回-1。CoreMark保留原ee_printf格式器和许可文字，通过同一putchar输出。UART IRQ软件队列32字节、有效容量31字节，满时丢弃新字节；本轮定向测试为4字节，不宣称任意连续流量无丢失。当前只有UART IRQ源，关闭UART IRQ的BSP接口同时禁用CPU中断；没有CLINT/PLIC或真正timer IRQ发生器。
