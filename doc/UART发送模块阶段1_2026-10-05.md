## 2. 模块与发送协议

新增 `myriscv/uart_tx.v`，默认参数 `CLK_HZ=93_750_000`、`BAUD=115_200`。

| 端口 | 方向 | 含义 |
| --- | --- | --- |
| clk | input | 93.75 MHz 工作时钟 |
| resetn | input | 低有效异步断言复位；调用方同步释放 |
| tx_data[7:0] | input | 待发送字节 |
| tx_valid | input | 发送有效信号 |
| tx | output reg | 注册串行输出，空闲/复位高电平 |
| tx_busy | output wire | START/DATA/STOP 全帧期间为 1 |
| tx_ready | output wire | 复位释放且 IDLE 时为 1 |

仅在上升沿 `tx_valid && tx_ready` 接受并锁存数据。忙时脉冲不接受、不排队；调用方若需要稍后发送，应保持 valid 和待发送数据至握手。valid 持续为高表示每次 ready 时都有一个新字节，不是边沿触发接口。所有输入属于 clk 域，没有内部跨时钟同步器。

状态为 `IDLE → START → DATA(bit0…bit7) → STOP → IDLE`。接受沿立即输出低起始位，每位完整保持 814 周期；发送锁存字节的 LSB 到 MSB，再保持高停止位 814 周期，随后退出 busy。下一个字节可在再下一个上升沿接受，因此连续发送时字符间有 1 个工作时钟的 idle high，不会缩短停止位。

分频计算：`BIT_CYCLES=(CLK_HZ+BAUD/2)/BAUD=814`，只产生计数到期使能，不生成新时钟。计数器为 10 位。实际波特率 `93_750_000/814=115171.990172 baud`，相对 115200 为 `−0.024314087%`；bit 时间 8682.666667 ns，10 位帧时间 86826.666667 ns。此误差只考虑分频，不包含实际板级晶振误差。

分数累加器/NCO 可按 813/814 周期交替给出 bit tick，降低平均误差，但引入 1 个时钟的位长变化及额外累加控制。当前整数分频误差很小，固定每位周期更便于实现与检查，故本阶段选整数分频。正参数且四舍五入分频值至少为 1 才是合法配置；本轮验证默认配置。

## 3. 独立 Testbench 与实际验证

新增 `source/tb_uart_tx.v`，仅例化 `uart_tx`，无 CPU、DDR、总线或 IP 依赖。检查器只观察外部端口，不访问 DUT 状态、计数器或 localparam。

- 独立串行接收检查：检测 TX 下降沿，以标称 `1e9/115200 ns` 的半位位置检查起始位，之后在八个数据位中心依次写入 `received[0]…received[7]`，最后检查停止位中心为高；按数组比较 `48 65 6c 6c 6f`，自动确认 `Hello`。
- valid 连续保持，握手后更新下一字符，检查最早 ready 接受、字符间隔、解码次数、接受次数与完成次数；完成后观察超过一帧，检测重复或意外排队字符。
- 外部逐周期模型检查 10 位整帧，每位必须是 814 个时钟，包括相邻相同数据位、完整停止位、busy/ready 边界；额外监视非时钟边沿 TX 跳变。错误打印具体阶段信息；解码错误打印索引、期望和实际字节；全局超时防止漏字符或卡住。
- 额外解码 `00 ff 55 aa 01 80`，覆盖恒定数据、交替数据、LSB/MSB 边界。在发送 00 的 start/data/stop 各位期间共注入 10 次 busy 请求脉冲并修改输入数据，检查原帧不变、无排队发送。
- 检查初始复位屏蔽请求；在发送中、两个时钟边沿之间再次断言复位，立即检查 TX idle high、busy=0、ready=0。复位后观察无残留帧，再发送并解码 R。主动中断的帧不纳入正常串行解码比较。

TB 时钟精度为 1 fs，ModelSim 使用 `-t 1fs`，避免 93.75 MHz 时钟在较粗粒度上的量化偏差。首次运行发现帧间隔实数容差 0.001 ns 小于 1 fs 时钟舍入累计量，已将帧间隔容差改为 0.01 ns；814 周期逐位断言保持严格不变。没有修改发送 RTL 来绕过检查。

新增 `sim/uart_tx/run_uart_tx.tcl`，独立 `uart_tx_work`，直接用库路径，不改任何 modelsim.ini、厂家脚本、PDS 文件或原有回归入口。编译/运行出错退出码 1；仅 TB 最终 test_pass=1 时退出码 0。仿真库和波形由现有 .gitignore 排除，保留日志 `sim/uart_tx/uart_tx.log`。
