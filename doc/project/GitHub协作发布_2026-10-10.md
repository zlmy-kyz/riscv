# GitHub 协作发布（2026-10-10）

目的：将当前 SoC 开发基线提供给摄像头与 CNN 开发同学。远端为 `zlmy-kyz/riscv`，协作入口为 [摄像头与CNN开发交接](摄像头与CNN开发交接_2026-10-10.md)。本次仅整理发布与新克隆依赖，没有开发摄像头/CNN/DMA，也没有运行 PDS。

发布范围：

- `myriscv/` 主 RTL、`RISCV.pds`、约束与主 IP 配置/生成初始化内容；2B 计数器直接在原有三个 `.v` 中。
- CoreMark 原源包、Loader/BSP/独立测量软件、构建和 PC 下载工具、仿真 TB/模型/脚本。
- 主 IP 引用的 Loader ROM/RAM DAT、对应 ELF/清单，以及 BSP 成功应用和最终测量版本 c 的固定构建产物。DAT/BIN/ELF 保持原字节，不为此次发布重新生成。
- 分类文档、已有精选验收结果及三个迁入前 RTL 快照。三个快照只用于已有缺口的回归比较，不是另一套设计入口。

不上传：PDS 产物/位流、ModelSim 编译库、完整冻结档案、板级成功快照、编译器发行包和大部分本地运行日志。已有成功文件仍保留在本机。历史脚本依赖的本地部署门控不会因发布而成为新克隆可用的部署许可；新主设计必须重新生成、审查并绑定位流。PDS 编译、综合、布局布线由用户执行。

源码复现入口：

```powershell
C:/python/python.exe -B doc/project/check_doc_links.py
C:/python/python.exe -B sim/cpu_performance_2b/run.py --suite oracle --tag clone_oracle

```

本机工具安装位置见 [AGENTS](../../AGENTS.md)。完整 DDR3 IP/PHY/物理模型的两条定向入口仍按 AGENTS 执行；此发布检查不替代既有主 RTL 完整 DDR 回归和后续新硬件实板验收。主 RTL 六组回归结果在 `sim/cpu_performance_2b/build/main_integration_20261010_a.json`；计数口径、具体 PASS 范围及已知 FENCE.I/ma_data 缺口见 [主 RTL 集成记录](../cpu/CPU性能计数器2B并入主RTL_2026-10-10.md)。当前计数器主工程实板仍 NOT_TESTED，原 CoreMark 实板成绩属于此前成功硬件。

`run.py` 保护输入检查允许新克隆尚未生成位流；本机已有位流时仍纳入前后哈希保护。实际 GitHub 更新以提交及远端分支核验为准。
