## 当前已有基础

- 单核 RV32I CPU、DDR 取指/数据读写、ROM 启动和 CPU 从片内 RAM 复制程序到 DDR 的路径已经存在。
- 当前板级 RESET_PC=0，DDR_BASE=0x40000000，core_clk=93.75 MHz。
- simple_mmio 的 0x10000008 是 32 位周期计数器，可由移植层用 volatile MMIO 读取。当前 CSR 白名单没有 cycle/mcycle，不能直接套用 rdcycle 计时移植。
- TEST_STATUS 位于 0x10000010，可显示运行及终态；LED 仅提供状态，没有成绩读回通道。

## 尚需准备

| 项目 | 所需配置 |
| --- | --- |
| 工具链 | 支持 RV32I/ILP32 的裸机 GCC/binutils 和对应 libgcc；本次常见 RISC-V GCC 与 clang 命令均未在 PATH 找到，不等于机器其他目录未安装 |
| ISA/ABI | -march=rv32i -mabi=ilp32；若启动汇编使用 CSR 指令，按工具链版本使用 rv32i_zicsr。运行库必须同样匹配，不能混入 M/C/F/A 指令；乘除法用软件辅助函数 |
| C 启动 | startup.S/crt0 初始化 sp（16 字节对齐）和所需 gp，正确初始化 .data、清零 .bss，设置可诊断异常入口，调用 main，结束后上报并停留 |
| 链接布局 | linker.ld 将入口放在当前 ROM 装载器跳转的 DDR 起始地址 0x40000000，划分代码、只读数据、可写数据、BSS、栈和结果区；用 ELF/map 核对各区不重叠 |
| 移植层 | core_portme.h/core_portme.c/core_portme.mak，实现 portable_init/fini、start_time、stop_time、get_time、time_in_secs、ee_printf；按链接需要提供 memcpy/memset 等支持函数 |
| 装载镜像 | 新建独立 CoreMark 镜像与构建入口，ELF 转字镜像，生成匹配清单，重新生成对应 ROM/RAM IP。现有 16 KiB RAM 尾部 16 字节存清单，装载内容和布局必须适配；代码、rodata、初始化 data 是否能容纳须编译后确认，BSS/栈不必存入镜像 |
| 结果读取 | 仿真可把文本写入结果缓冲/MMIO 后由 TB 读取；实板可增加 UART TX 或使用可读回的调试接口。只用 LED 无法取得成绩、CRC 或计时值 |
| 超时策略 | 当前 LED 在 5 秒后锁存超时显示，正式基准至少 10 秒，会冲突；须给 CoreMark 独立超时策略。此超时不复位 CPU。延长阈值时核对 parameter integer 与 32 位计数器范围 |

裸机配置起点：TOTAL_DATA_SIZE=2000、MULTITHREAD=1、MEM_METHOD=MEM_STATIC、SEED_METHOD=SEED_VOLATILE、MAIN_HAS_NOARGC=1、HAS_FLOAT=0、HAS_TIME_H=0、USE_CLOCK=0、HAS_STDIO=0、HAS_PRINTF=0；输出由自定义 ee_printf 提供。优化先使用 -O2，固定 ITERATIONS 用于试跑，随后按实际计时选择正式迭代数。

## 计时与成绩

- 以 MMIO CYCLE 起止无符号差值作为 ticks，TICKS_PER_SEC=93750000；只计迭代区间，不将 DDR 训练/装载计入。
- 32 位计数器约 45.8 秒回绕；单段小于一个回绕周期可用无符号减法处理一次跨界。更长区间需要可靠扩展或新增宽计数器，不能仅靠起止两次采样推断多次回绕。
- 单线程 CoreMark=iterations/seconds；CoreMark/MHz=CoreMark/93.75。可保存原始 iterations/ticks 在主机计算，避免裸机浮点格式化和整数精度损失。
- 正式计时必须至少 10 秒，TOTAL_DATA_SIZE=2000，performance seeds 为 0,0,0x66，validation seeds 为 0x3415,0x3415,0x66，两套均需验证成功。短试跑可检查 CRC，但官方程序会把不足 10 秒记为无效，不能据此报告正式分数。
- 保持官方算法源码，适配 core_portme*，记录编译器、全部参数和代码/数据存储位置。当前从 DDR 执行且无 Cache 的分数反映 CPU 和 DDR 路径；对比片内执行时应明确区分存储配置。
